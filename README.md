# ZRSParser

## ZRS file

ZRS is the model format used by Z2's engine. ZRS file contains information about many 3D models, including information about Mesh, Texture, Material, Dummy, Spinner, animator, etc. 

## Implementation

This program can read a number of 3D elements from a file into the cache.
The cached data is then converted into a file in 3DSMAX format. The current output file format is an Obj file.
